# 章节子代理任务与交接

默认串行制作。用户要求或允许子代理时，可以让一个子代理完整制作一章，或把不同章分别交给代理；不能同时让多人改同一章，也不要让多个代理依次只写来源片段，留下未整合的材料堆。

首次制作该课程时，主代理先固定课程映射、模板与深度口径。宜先完成一章并自行审校，再用相同标准分发其余章；用户没有要求样章确认时无需停下等待。并发数量按可用工具和资源调整，不假定环境支持特定工具名。

## 可直接使用的任务说明

```text
任务：制作 [课程名] 第[N]章 [标题]，保存分章教材，完成该章全部阶段与自检。

约束：读取 exam-driven-notes-builder/SKILL.md、references/formatting.md、references/biology.md。
来源优先级与流程：PPT + 可用试卷粗版 → 可用辅导书补强 → 指定课本全面补全。

输入（主代理填写实际路径及范围）：
- PPT：文件ID、路径、幻灯片范围及需要查看的图。
- 课本：书名/版次、路径、章/节、物理页与印刷页。
- 可选试卷/辅导书：实际资料和范围；没有则写未提供。
- 框架：本章主题顺序、相邻章连接点、已经确认的术语口径。

允许写入：缓存/[课程名]/章节/第[N]章/ 以及本章唯一成品文件。
共享资料登记、课程映射、_进度.md、总稿由主代理维护，子代理不改。

交付：本章md + 覆盖表 + 审校记录。
自检：PPT有效要点、题目子问、课本各节重要内容逐项对照；事实疑点核原图；lint-notes错误清零。
不要伪造题目、原文定义、页码或频次。无法确认的关键问题保留待核实，报告实际完成阶段。
最终回报：输出路径、已读来源范围、覆盖缺口、冲突处理、格式检查结果、实际预览状态、跨章关联。
```

## 主代理验收

子代理“完成”只是交接信号，不等于章节审校通过。主代理检查实际文件，抽查一个关键机制、一张对比表、一条定义及对应来源；有题时抽查题目子问是否可回答。优先复核子代理报告的冲突和 OCR 疑点。

核对各章结构、术语和展开深度，检查跨章关联和重复讲解。不达标时给出具体缺口，交回原代理补正；只改受影响的内容。章节通过后主代理更新共享进度，全范围通过后合并。代理中断则从该章审校记录恢复，不重做已经完成的阶段。
