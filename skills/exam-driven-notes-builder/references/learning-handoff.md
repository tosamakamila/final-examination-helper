# 教材制作到学习系统的交接

本参考说明与采用四分区 Markdown、教学单元和待审闪卡的学习系统如何交接。表中行为来自一种已有适配方案，不是所有学习系统的通用实现。本 skill 可以独立生成教材；只有用户提供目标学习系统并要求接入时，才核对该系统的真实接口，不要求安装额外学习应用。

## 四个分区各自承担的功能

| 制作分区 | 学习端用途 | 上游制作要求 |
| --- | --- | --- |
| 一、名词解释 | 专用导入脚本切出整区，生成待审闪卡；审核后才进入正式卡片 | 名词标题明确、定义准确、附加信息适量；不用数字步骤制造假名词；保留原句优先 |
| 二、核心知识点整合 | `### （一）大主题` 切成教学单元；当前课堂读当前单元及相邻主题标题 | 单元内含完整定义、关键机制和成立条件，不靠其他分区补全 |
| 三、知识联系与记忆框架 | 学生复习与章级框架；当前直讲组装不自动附整章框架 | 保留知识关系与辨析，不放只能在这里找到的必需知识，不输出口诀 |
| 四、课后习题 | 原题单独提取到课后题功能，不作为当前教学单元正文 | 保留原题、编号、选项、必要图；不加答案或标注 |

正文里的【考题照应】会从讲课窗口和名词卡中过滤，保留它供学生复习。新造的“定义来源／资料依据／覆盖状态”等标签没有同样的过滤约定，放在缓存的来源、定义和覆盖记录里，避免混进课堂与卡片答案。资料有争议时在学习内容中说明科学条件，完整出处另记缓存。

## 章节和单元不是同一层

输出章对应学校课程大纲，可以由多个课本章合并，或将一个课本章拆成不同课程章；同一输出章也可以关联多个课次文件。原始文本拆章只做资料索引，不等于最终课程章节重组。

当前专用解析器以扫描顺序分配 `ch01/ch02/...`，以主题出现顺序分配单元索引。单独导入 `# 第3章` 会成为 `ch01`；删除中间章、改变排序或重新划分主题也会影响进度对应。文件名正确和格式检查通过不能证明学习端身份正确。

第二部分不要在第一个大主题前写正文介绍，当前解析器会把它另建“引入”单元。围栏只用来放公式、流程和树，不在正文内嵌含 `# 第N章`、`##` 分区或 `### （一）` 的 Markdown 示例；学习端的标题扫描尚不能像上游格式检查那样自动忽略全部围栏。

## 导入入口必须明确

目前有两类不同入口：

- **普通页面文件导入**：接入文件并建立正文和章节索引，通常进入 `ocr_only/chapter_source` 路线；不能据此宣称已转教学单元或名词闪卡。
- **专用分区教材导入**：`tools/course_import/import_three_part_course.py` 生成正文、`units.json`、章节索引、课后题及名词待审材料，进入 `teaching_units` 路线；它会切名词区，并从切后的同一份正文派生行号。

不要把普通上传、原课本转单元工具和专用分区导入混用。`textbook_to_units.py` 服务普通课本，它会写新的初始单元进度，不能作为既有分区课程的安全更新工具。

用户只要求生成教材时，完成文件与交接记录即可；不能顺带重导入课程、重置进度、导入正式闪卡或启动模型课堂。用户明确要求接入学习系统时，再按所选入口执行实际导入。

## 导入前准备和验收

1. **确定权威源**：记录本次合并稿的实际路径、范围和内容版本，不凭“最新”字样选择文件。文件名中的“最新”或“最终”不能证明它与当前学习端使用的版本相同，应比较实际内容及索引。
2. **确认已有学习状态**：核对课程是否存在、已用的章ID、单元标题与顺序、当前停靠点和已完成单元。不能直接把当前学过的课程当作新课覆盖。
3. **只读解析候选**：在内存或隔离工作区用学习端真实解析函数检查章数、单元数、名词数及题目数；检查零单元、意外引入、漏题、章ID错位和不同编号格式。不能运行会写正式课程的 `main()` 充当检查。
4. **比较结构影响**：内容纠错、换定义、补机制也会改变正文散列及行号；增删章或主题需要明确进度迁移映射。保留 `taught_units.json` 文件不等于进度仍然对应新结构。
5. **实际接入后核验**：正文与索引来自同一版本；章ID/标题对应课程大纲；名词转待审而非自动成正式卡；章后题来源是原题；当前章、续课点及已学进度有效。未做真实课堂验证时只能说结构接入通过。

专用导入脚本覆盖多份课程数据且不提供完整的进度迁移或只读预演，不能在上课中更新正文。制作端持续修改，学习端使用已确认版本；准备好交接后再同步。定义若为资料归纳，交接清单注明，审卡时核查，不能用旧导入器的“原文定义”描述冒充逐字来源。

## 交接记录

保存到 `缓存/[课程名]/学习交接.md`：

```markdown
权威源：实际路径、版本/散列、课程范围。
目标：学习项目路径、课程名、所选导入入口。
制作状态：哪些章通过审校，哪些尚未完成。
只读解析：章ID和标题、各章单元数、名词及题目数、问题清单。
变更影响：章/主题是否增删或改序，已学进度和停靠点如何对应。
定义口径：哪些据资料归纳，哪些需要人工复核。
执行状态：仅备好文件 / 已导入结构 / 已验收课堂；不得混为一谈。
```

没有学习项目源码或版本改变时先核对实际导入接口；不能按本文推断新系统的行为。
